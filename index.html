Design System & Components

A reusable component library built on Inter, an 8 px spacing grid, and a token set for color, type, spacing, and radius. Each component lists its variants and states so developers and designers use the same definitions.

1. Color tokens

Four families: Primary (actions), Secondary (supporting actions), Neutral (text and surfaces), Feedback (status messages). Source: tokens.json.

6. Modal dialog

Width 420 px, padding 32 px, radius 12 px, shadow 20 px. Actions align right: secondary action (Ghost) then primary action. Destructive actions use the error token on the primary button.
